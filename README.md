# Mes mini-sites

Portail personnel hébergé avec GitHub Pages.

## Organisation

- `index.html` : page d’accueil et accès aux différentes rubriques
- `pharmacie/` : ressources et outils autour de la pharmacie
- `ipad/` : astuces et usages de l’iPad
- `recettes/` : recettes et idées de cuisine
- `voyages/` : itinéraires et inspirations
- `education/` : ressources éducatives

Chaque dossier possède son propre `index.html`. Les liens sont relatifs afin de fonctionner directement avec GitHub Pages.
